Keep one note per durable fact, with a stable id:

- `people/` — one file per person
- `projects/` — one file per project (hub), details nested underneath
- `guidelines/` — standing policy (do-not-push-sandia, 8080 rule, …)
- `workflows/` — only reusable procedures, not one-off investigations
- `scratch/` — anything with a date or a ticket; expires in a week

Prefer `append` / `edit` over `write` (`write` overwrites the whole file).
